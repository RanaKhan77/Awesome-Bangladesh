📚 Awesome lists & communities 20 verified entries

Sibling lists and community directories that map the wider Bangladeshi ecosystem — developer directories, FOSS indexes, portfolios, and the older Bangla-computing lists that predate this one. We link rather than duplicate: if another list covers a niche better, it belongs here. Community organisations are listed for their community role, not their git activity, and sleeping lists stay listed when they are still the best map of their territory — with their dormancy stated plainly.

  • tech-companies-in-bangladesh The biggest Bangladesh-focused list on GitHub: tech companies with names, stacks and hiring signals, maintained for job seekers by the MBSTU Programming Club. MIT ee list
  • awesome-bangla The long-running Bangla-computing list whose scope is the language rather than the country — fonts, keyboards, NLP and tools, a complement to this list rather than a competitor. Slow maintenance, still the best map of its niche. see notes ee list
  • made-in-bangladesh The historic seed list of BD-made software — where the "made in Bangladesh" idea on GitHub started. Dormant since 2023, preserved as ancestry. MIT ee list
  • Awesome-Bangladeshi-Devs Data-driven directory of 3,600+ Bangladeshi developers, generated from GitHub profiles — a people index, useful for finding collaborators and hiring. MIT ee list
  • Awesome-Bangladeshi-FOSS Bangladeshi FOSS projects across 12 sections — the project-side counterpart to the devs directory above. see notes ee list
  • Awesome-Bangladeshi-Portfolios 2,500+ developer portfolios — a gallery of how Bangladeshi developers present themselves, and a benchmark set when designing your own. Apache-2.0 ee list
  • awesome-directory-of-bangladeshi-software-companies BD software company directory from the BDDevs community — company profiles with an eye toward outsourcing and partnership decisions. CC-BY-4.0 ee list
  • Awesome-Cybersecurity-Bangladesh Cybersecurity companies, clubs and degrees in Bangladesh — the local industry map for students choosing a path and companies finding partners. see notes ee list
  • bangladesh-tech-community Bangladeshi tech professionals directory — a structured people index from the algolyte research community. see notes ee list
  • awesome-gob Bangladeshi government web services directory — the state's online presence catalogued in one place. MIT ee list
  • awesome-cyber-security-heaven Curated global cybersecurity resource list maintained in Bangladesh — the sibling project to this list, covering security worldwide. see notes ee list
  • Bengali.AI Volunteer research community for Bengali language AI — the organisation behind the Kaggle speech, handwriting and grapheme competitions that seeded much of today's Bengali NLP, with open datasets on their Hugging Face organisation. see notes ee list
  • python-bangladesh Python community of Bangladesh (PyBangladesh) — the org behind the national Python meetups and conference series. see notes ee list
  • Stack-Learner Bangla programming education community — structured learning paths in Bangla for full-stack development. see notes ee list
  • BDOSN Bangladesh Open Source Network — the long-standing nonprofit promoting open source nationally, organiser of programming contests and camps. see notes ee list
  • pathao-eng Pathao's open-source engineering projects — production code from one of Bangladesh's largest tech companies, including the official WooCommerce courier plugin in the fintech section. see notes ee list
  • Deshi-Startup Open-source startup manual and community in Bangla — how to build a Bangladeshi startup, written in Bangla, maintained as a public playbook. MIT ee list
  • OpenBangla Community behind OpenBangla Keyboard and its Rust input stack — the modern continuation of the Avro lineage, see the Bangla NLP section. see notes ee list
  • OmicronLab Historic home of Avro Keyboard — the input method that put Bangla on millions of machines. Current repositories are mirrors of the pre-GitHub project, kept for the record. see notes ee list

✨ Editor’s picks

tech-companies-in-bangladesh

The biggest Bangladesh-focused list on GitHub — company names, stacks and hiring signals for job seekers. When people ask "where can I work in Dhaka?", this is the link that answers them.

Bengali.AI

The volunteer community that did more for Bengali language AI than any institution — the Kaggle competitions it ran produced the speech, handwriting and grapheme datasets that today's Bangla NLP work is built on, and its Hugging Face org keeps them open.

bangla-corpus

A Dhaka-maintained index of Bangla corpora — the same author maintains the bnlp toolkit. A good companion when hunting for a specific Bangla dataset by task.

How this section is verified

  • Every link is fetched live at verification time — dead links are removed, not kept for history.
  • Bangladesh connections are evidenced (profile location, org page, or the product's own docs) — see the scope rules.
  • Dormant items (3+ years without activity) move to the legacy file with their last-activity date.
  • Licence information is quoted as the publisher states it; gaps are flagged with ⚠️ rather than guessed.
