# Support

## Where to go for what

| You need | Where to go |
|---|---|
| Suggest a new entry for the list | [Open an issue](https://github.com/RanaKhan77/Awesome-Bangladesh/issues/new/choose) with the *new entry* template — read [CONTRIBUTING](CONTRIBUTING.md) first |
| Report a dead link, wrong licence, or misplaced entry | [Open an issue](https://github.com/RanaKhan77/Awesome-Bangladesh/issues/new/choose) with the *correction* template |
| Ask whether a project qualifies | Read [scope and eligibility](docs/scope-and-eligibility.md) and the [curation policy](docs/curation-policy.md); if still unsure, open a plain issue and ask |
| Report a security or safety problem with a listed link | Follow the [security policy](SECURITY.md) — report privately, not in public issues |
| Get help using a listed project | Ask that project's maintainers — we curate the directory, we do not support the software in it |

## Response expectations

This is a volunteer-maintained list. Expect replies within a few days, not
hours. Issues with the *verification* label (helping confirm queued items) are
the fastest way to get attention — a well-evidenced verification PR is usually
merged within a week.
