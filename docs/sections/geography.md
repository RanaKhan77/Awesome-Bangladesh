# 🗺️ Geography & open maps

Administrative boundaries, geocoding libraries and map data for Bangladesh — the division → district → upazila → union hierarchy that every BD app eventually needs. The classic datasets here are the most-starred Bangladeshi repositories on GitHub for good reason. Boundary files are checked for actual data content, not just a README and a logo.

## Editor's picks

### [bangladesh-geocode](https://github.com/nuhil/bangladesh-geocode)

The canonical administrative-boundary dataset, lat/long included — the first import of countless Bangladeshi apps.

### **Bangladesh geojson shapefiles**

Division and district polygons ready for Leaflet and Mapbox — pairs with geocode's point data.

## How this section is verified

- Every link is fetched live at verification time — dead links are removed, not kept for history.
- Bangladesh connections are evidenced (profile location, org page, or the product's own docs) — see the [scope rules](../scope-and-eligibility.md).
- Dormant items (3+ years without activity) move to the [legacy file](../../legacy.md) with their last-activity date.
- Licence information is quoted as the publisher states it; gaps are flagged with ⚠️ rather than guessed.
